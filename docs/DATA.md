# Data

Three datasets are bundled. They contain no local account configuration. File
sizes and SHA256 digests are recorded in [DATA_SHA256.json](DATA_SHA256.json).

| Dataset | Included files | Approximate size |
|---|---|---:|
| Activity | `data/activity/processed/data.pt` | 15.7 MiB |
| Taxi | `Temporal Point Process/taxi/{train,dev,test}.pkl` | 3.2 MiB |
| MuJoCo | `Generation/irregular_generation_diffmn/table1_data/mujoco_training_36.pt` | 17.8 MiB |

## Activity

The processed cache contains 25 original activity recordings. The loader uses a
fixed seed=42 split of 15/5/5 recordings for train/validation/test, then creates
3,318/1,007/1,075 four-second windows with a one-second stride.

Source: Vidulin et al., *Localization Data for Person Activity*,
[UCI repository, DOI 10.24432/C57G8X](https://archive.ics.uci.edu/dataset/196/localization+data+for+person+activity),
licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
This repository distributes the preprocessed tensor, not a new independent dataset.
The transformation is implemented in `lib/person_activity.py`.

## Taxi

The included benchmark pickle files contain 1,400/200/400 sequences in
train/dev/test. The test split yields 14,420 valid next-event contexts. Data retain
their benchmark split; the CKA adapter performs deterministic context sampling.
The format follows the [EasyTPP data pipeline](https://github.com/ant-research/EasyTemporalPointProcess).
Only the trusted bundled pickle files should be used with the pickle loader.

## MuJoCo

The bundled tensor has shape `[4620,36,14]` (7 positions and 7 velocities).
It was regenerated using real Hopper physics following
[TimeCraft Diff-MN's HopperPhysics recipe](https://github.com/microsoft/TimeCraft/blob/main/Diff-MN/datasets/mujoco_physics.py),
with data seed=123, dm-control=1.0.46 and mujoco=3.13.0. The adjacent
`.provenance.json` records the method and data hash. The original benchmark tensor
was unavailable; this is a new physical simulation, not a bit-identical recovery.

The first 3,696 trajectories train the model and the remaining 924 are held out.
Training on this tensor needs no physics installation. To generate additional
lengths (existing files are preserved):

```bash
python -m experiments.cka.install_physics
python -m experiments.cka.prepare_mujoco --lengths 12 24 36
```

The installer verifies official Hopper dynamics. For Python 3.13 it omits the
unused maze-only `labmaze` dependency; it does not substitute or modify the Hopper
physics implementation. Generation fails if required real data files are absent.

## Optional datasets

The corresponding model entry points are retained, but the following data are
not bundled. Supply the processed files before running those task scripts.

### Classification

```text
data/P12data/processed_data/PTdict_list.npy
data/P12data/processed_data/arr_outcomes.npy
data/P12data/splits/phy12_split1.npy
data/P19data/processed_data/PT_dict_list_6.npy
data/P19data/processed_data/arr_outcomes_6.npy
data/P19data/splits/phy19_split1_new.npy
data/PAMAP2data/processed_data/PTdict_list.npy
data/PAMAP2data/processed_data/arr_outcomes.npy
data/PAMAP2data/splits/PAMAP2_split_1.npy
```

`lib/Dataset_MM.py` defines the required record, outcome and split-array format.
Classification requires these processed arrays and fixed split indices; placing
the regression PhysioNet tensor here is not sufficient. Raw-data preprocessing for
all classification datasets is outside this compact release.

### Other regression and generation tasks

```text
data/physionet/processed/set-{a,b,c}_0.0.pt
data/ushcn/processed/ushcn.pt
data/mimic/mimic.pt
Generation/irregular_generation_diffmn/table1_data/stock_data.csv
Generation/irregular_generation_diffmn/table1_data/energy_data.csv
```

Regression loaders also support their documented raw formats in `lib/`.
Access-controlled MIMIC data are not included. Stock/energy generation expects
real numeric CSV input with a header; it does not synthesize replacement data.
Sines are generated by the source's deterministic synthetic-data method.
