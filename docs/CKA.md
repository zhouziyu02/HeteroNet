# CKA protocol

We use centered linear CKA from
[Kornblith et al., ICML 2019](https://proceedings.mlr.press/v97/kornblith19a.html):

`CKA(X,Y) = ||Xc.T @ Yc||_F² / (||Xc.T @ Xc||_F ||Yc.T @ Yc||_F)`.

Rows are paired held-out samples. All selected rows are collected before one
global, per-column centering operation. Computation uses float64; minibatch CKA
values are not averaged. No feature-wise standardization is applied. All-missing
rows are excluded jointly; constant representations are reported as undefined.

## Endpoints

The first endpoint is the event encoder's normalized output, averaged over only
observed time/channel positions for each sample. Missing values and padding are
excluded. The final endpoint follows the actual task forward path:

| Task | Final endpoint | One row |
|---|---|---|
| Interpolation / Extrapolation | interaction global + kernel global, before query readout | held-out 4-second Activity window |
| TPP | `interaction.global_proj`, before the intensity head | valid next-event context |
| Generation | `ITSPM.forward`, including `cls_fusion`, before `cond_proj` | held-out observed trajectory condition |

This is an early-event versus final-backbone comparison, not a comparison of the
first and last Transformer blocks. Taxi has one mixer block and a separate ITSPM
implementation without the kernel branch. Activity prediction also uses variable
and token representations beyond the global endpoint measured here.

For generation, ITSPM receives `(obs_times, obs, mask)`. The downstream denoiser
receives the current diffusion state, observed data, mask, and diffusion-step
embedding; it predicts noise with shape `[B,36,14]`. CKA measures the fixed
observation-condition encoder, independently of diffusion noise or step.

## Training and selection

| Task | Training settings | Checkpoint selection |
|---|---|---|
| Activity, both tasks | d=128; 3 mixers; batch=32; AdamW 5e-4; StepLR(30,0.5); max 1000 epochs; patience=10 | minimum validation MSE; reference epochs 33 and 48 |
| Taxi | d=64; 1 mixer; context=16; batch=128; Adam 5e-4; 20 epochs | maximum validation log-likelihood; reference epoch 20 |
| MuJoCo | d=96; batch=128; AdamW 1e-3; 100 diffusion steps; 200 epochs | fixed final epoch 200 |

Training seed is 1. Activity stopped at epochs 43 and 58. Test metrics and CKA never
select checkpoints. Taxi omits stochastic thinning metrics during CKA training;
generation omits the Gaussian baseline evaluation. This preserves the objectives
but does not claim to reproduce historical random-number trajectories.

Activity uses all 1,075 test windows; Taxi samples 2,048 of 14,420 contexts without
replacement using seed 1. Generation uses all 924 test trajectories (selection
seed 31416 has no subsampling effect). The nominal missing rate is 50%; restoring
first/last steps gives a measured test observed fraction of 0.527958.

Activity follows the original train+validation min/max normalization. MuJoCo
follows the original loader: min/max across loaded trajectories, then channel
z-score using training trajectories. Its data were regenerated by real Hopper
physics; see [DATA.md](DATA.md).

## Interpretation and verification

These are descriptive, single-seed representation similarities. They do not
measure prediction or generation quality, and do not alone establish over-smoothing.
Overlapping windows and same-sequence event contexts are not independent records.
Different row units and architectures prevent ranking tasks by these values.

Each reference directory contains `results.json`, `representations.npz` (first,
last, sample_ids), and `training.jsonl`. The supplied arrays have been checked with
an independent centered Gram-matrix formula, and reproduce the reported CKA values
within floating-point precision. `summarize` verifies row counts, unique paired
IDs, metadata, and numerical agreement before creating the table and figure.

Full retraining may vary with hardware and software. In particular, the original
tokenizer's tied top-k selection can differ across devices. Use the saved T4
arrays for exact numerical verification of the reported values.
